# Data
This project uses two datasets from the University of Helsinki cat research group. Both are free to use if you credit the authors (licence: CC BY 4.0).
The files are exactly as downloaded.

## The two files
1. Feline_dataset.xlsx
   Feline behavior and personality survey data
   Authors: Mikkola, Salonen, Hakanen, Sulkama and Lohi
   DOI: 10.6084/m9.figshare.14899077.v2
   What it has: 4,316 cats, with owners' answers about their cat's behaviour.

2. Feline_variable_data.xlsx
   Feline environmental variables data
   Authors: Mikkola, Salonen, Hakanen and Lohi
   DOI: 10.6084/m9.figshare.21118915.v3
   What it has: 3,255 cats, with details about their home, care and background.

## How they fit together
Both files have a column called CATID. It is a number that identifies each cat, so the files can be matched up. All 3,255 cats in the second file are also in the first. This project uses those 3,255 cats.

## Where to download them
Feline_dataset.xlsx: https://figshare.com/articles/dataset/Feline_behavior_and_personality_survey_data/14899077
Feline_variable_data.xlsx: https://figshare.com/articles/dataset/Feline_environmental_variables_data/21118915
